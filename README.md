## Descripción

Se resuelven cuatro problemas (recibo de luz, calificación final, total de compra
y estacionamiento) escribiendo primero la especificación completa de cada uno y
usando a GitHub Copilot únicamente como implementador de esa especificación.
El historial de commits deja evidencia de que la especificación siempre precede
al código.

## Cómo ejecutar

Desde la carpeta raíz, con el entorno virtual activo:

```
python main.py
```
